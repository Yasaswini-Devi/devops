# DevOps Exam Preparation Kit

This zip archive contains all working code files covering your exam sets:

## Included Files
- `app.py`: Flask REST API backend
- `requirements.txt`: Python dependencies (Flask, pytest)
- `Dockerfile`: Container configuration for Flask
- `test_app.py`: Unit tests generating JUnit XML reports
- `main.tf`: Terraform script with standard execution workflow
- `k8s/configmap.yaml`, `k8s/deployment.yaml`, `k8s/service.yaml`: Kubernetes manifests
- `Jenkinsfile`: Complete CI/CD pipeline script
- `argocd-app.yaml`: GitOps ArgoCD application configuration

## Quick Start
1. Unzip this package.
2. Push the files to your GitHub repository.
3. Clone into Killercoda or Codespaces and run your commands.
